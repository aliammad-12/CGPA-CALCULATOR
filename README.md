A simple C++ program that calculates the semester GPA and overall CGPA based on course grades and credit hours.

Features
Takes the number of courses as input
Accepts grades and credit hours for each course
Calculates grade points and semester GPA
Calculates overall CGPA
Displays the final CGPA
Technologies Used
C++
Standard C++ Libraries
How to Run
Clone this repository.
Open the .cpp file in any C++ compiler or IDE.
Compile and run the program.
Enter the required course information.

Enter grade for course 1: A
Enter credit hours: 3
